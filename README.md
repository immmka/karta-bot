# Telegram-бот для карты клиентов

## Что умеет
- `/add Название\nАдрес` — добавить заведение + автоматически найти координаты
- `/status Название статус` — изменить статус (работаю / не работаю / потенциал)
- `/find текст` — поиск
- `/stats` — статистика
- `/list` — последние записи

## Как запустить

### Вариант 1. Локально (для теста)
1. Положи файл `service_account.json` (тот самый ключ) в эту же папку.
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запусти:
   ```bash
   python bot.py
   ```

### Вариант 2. Бесплатный хостинг (Railway / Render)
1. Создай аккаунт на [railway.app](https://railway.app) или [render.com](https://render.com).
2. Загрузи эти файлы + `service_account.json`.
3. Укажи переменную окружения `TELEGRAM_TOKEN` (можно оставить как в коде).
4. Запусти как Worker / Background Worker.

## Важно
- Файл `service_account.json` должен лежать рядом с `bot.py`.
- После настройки лучше перевыпустить токен бота в @BotFather и ключ сервисного аккаунта.
